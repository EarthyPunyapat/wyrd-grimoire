# M7 — Breadth: build roadmap

Built directly in stacked steps on `m7-breadth` (off `m6-characters`), as M5 and M6 were. Each step
ends green (`bun run check`, `bun run test:e2e` after `bun run build`) and is committed. One
whole-branch review runs at the end, then the M7 acceptance boxes and handoff.

Spec: [11](../../spec/11-subsystems.md), [12](../../spec/12-campaign-settings.md),
[04 progression](../../spec/04-characters.md#progression), [05 spellcasting + fantasy-core minimums](../../spec/05-genre-packs.md#the-spellcasting-plugin-fantasy-core),
[06 Living World + downtime](../../spec/06-world-and-story.md).

**Architecture:** every switch is campaign state in `CampaignSettings`; rules read toggles from state
and every change is a `SettingsChanged` event. Presets are pure functions over the toggle block.
Class levels, spells, strain, news and downtime results are engine events so they replay; new GameState
fields are defaulted on load and new sheet/equipment fields default for older snapshots. Pack content
grows through new zod schemas, compiled and namespaced like the rest, and all numbers stay in
`packages/core/src/tuning.ts`.

| Step | Delivers |
|---|---|
| **A** Settings, presets and locks | The full subsystem toggle set and the three presets; `GET/PUT /api/campaigns/:id/settings` with lock enforcement (dice, progression, hardcore, permanent marks) and a settings view carrying reason strings; the campaign Settings panel with greyed locked fields, presets, difficulty/lethality, content dials, narration and media; a mid-campaign toggle sweep proving every toggle is safe; decisions |
| **B** Pack breadth schemas | Zod schemas and loader support for `classes.yaml`, `spells.yaml`, `loot-tables.yaml`, `economy.yaml`, `calendar.yaml`, `naming.yaml`, `recipes.yaml` and `diseases.yaml`; `spellcasting` registered as a known plugin with its config schema; compiled-pack fields and reference checks; fantasy-core claims class mode and the plugin; decisions |
| **C** Class progression | Class levels from the XP thresholds (10 × n(n−1)/2), automatic class-skill and any-skill training, class features as talents, +1 attribute at levels 4 and 8, no HP from levels; class choice at creation (archetype → class mapping); `ClassLevelGained` event and reducer; Party tab class/level/feature display; decisions |
| **D** d20 end to end | Resolution chosen at creation (d100 or d20) and locked; d20 carried into quick start, generated campaigns and the settings view; sheet and Party display d20 modifiers instead of percentages; creation preview and mechanics lines read correctly; a full d20 campaign through the API and e2e; decisions |
| **E** Spellcasting plugin | The `spellcasting` plugin: spells as pack data, four schools, tier strain, cast checks, effect vocabulary (damage, heal, conditions, zone tags, movement, ward, summon, detect, illusion), critFailure miscasts, learning through talents/classes/teachers; `cast` action in exploration and combat; parser/narrator prompts, offline stand-ins and UI hints; decisions |
| **F** Living World, news and downtime | Story-mode switching keeps or freezes the threat clock; Living World weekly faction goals, NPC life events and job-board hooks; bounded `NewsPublished` state, Journal/Map news; a month-of-game-time test with visible faction events and news; downtime activities (train, craft, work, research, carouse, recover) as engine actions with time, checks, XP, money and improvement rolls; decisions |
| **G** Subsystems in play | Encumbrance (abstract/weight/slots), coins/wealth levels/haggling, time detail and lighting, weather effects, travel-encounter reduction, language barriers, ammunition, durability, crafting, survival needs and disease; each reads its toggle; toggling off keeps state and stops enforcement; a playable soak on every preset; decisions |
| **H** Timeline, export and backups | Branch list, fork/activate, save slots and load; Timeline tab with the current position marked; campaign export to a portable bundle, validated import into a new campaign, and server-side rolling backups with listing/download; decisions |
| **I** fantasy-core content | 6 classes, ~40 talents, ~25 weapons, 10 armours, ~60 gear items, ~30 spells, ~30 creatures, complete loot tables, economy, calendar, naming, recipes, diseases and 4 pregens; all original; count/reference tests and `pack validate`; decisions |
| **J** Acceptance and review | Whole-branch review, real findings fixed with regression tests, M7 acceptance boxes ticked, HANDOFF M7 section, final green check + e2e |

Owner-only checks after J: real-model play on each preset, a real Living World month, and spellcasting
narration on the configured providers.

**Status (2026-10-29):** stopped for handoff after steps A–E were partly built (settings/locks, pack breadth, class progression, d20, spellcasting foundations and most of the fantasy-core minimum content). F–J remain. See `HANDOFF.md` for the exact gaps.
