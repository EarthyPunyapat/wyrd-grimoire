# M6 — Characters and companions: build roadmap

Built directly in stacked steps on `m6-characters`, as M5 was. Each step ends green
(`bun run check`, `bun run test:e2e`) and is committed. One whole-branch review runs at the end.

Spec: [04](../../spec/04-characters.md) (creation, progression, companions), [13](../../spec/13-ui.md)
(sheet editor, Party tab), [15](../../spec/15-testing.md).

**Architecture:** creation stays outside the event log until the player commits. A creation draft
(already stored for pitch-first worlds) gains a draft sheet that every path edits, and the engine's
`validateCreation` stays the single gate. Progression and companions are engine state reached only
through events, so they replay. Approval, recruitment and XP are proposed by models and decided by
the engine.

| Step | Delivers |
|---|---|
| **A** Sheet editor and quick start | A draft sheet on the creation draft; `PUT /api/world-drafts/:id/sheet` validates and returns issues; a shared sheet editor (attributes, skills, talents, appearance, backstory, hand-added hooks) with live validation; pack pregens (`pregens.yaml`, 4 for fantasy-core) and pregens derived from a generated world's origins and backgrounds; the cheat-edit setting |
| **B** Form wizard | Archetype → attributes → skills → talents → gear → appearance and backstory, with per-field "suggest" calls (`sessionZero` role, offline stand-ins) |
| **C** Session zero | The interview loop (6–10 questions) with `propose_attributes/skills/talents/gear/appearance/hooks`, each validated against the budget; live sheet preview; backstory hooks (rival, missing person, debt, secret) committed as `backstoryHook` canon and placed into the world bible at campaign start |
| **D** Progression | Engine XP awards on quest stages, encounters, discoveries and chapter closes (`XpAwarded`); classless purchases (`AdvancementBought`); use-based marks and improvement rolls; hybrid; class levels for packs with class data; optional `suggest_xp`; the spend UI |
| **E** Companions | `CompanionJoined`/`CompanionLeft`; recruitment validation; sheets from statblocks or generation; AI/manual control and directives in combat; out-of-combat requests; approval from guard deltas (±10 per event, ±20 per scene) with thresholds at −50/−75/+50/+75; personal quests; banter; companion death setting; the Party tab |
| **F** Acceptance | The three creation paths end to end (server tests and e2e); hooks appear in the generated world; a companion is recruited, fights, gains and loses approval and leaves; decisions, spec notes, handoff, review |

Decisions start at D104.
