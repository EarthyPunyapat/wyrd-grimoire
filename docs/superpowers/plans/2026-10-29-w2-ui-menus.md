# W2 UI 2.0 U4 — the status screen (2026-10-29)

Spec: [Wyrd 2.0 design §12](../specs/2026-10-29-wyrd-2-design.md). Decisions: D150 (Reader
default), D151 (tokens and fixed signal accents), D152 (menus open full screen over the story).
Roadmap: [W2 roadmap](2026-10-29-w2-roadmap.md).

U4 replaces the separate panels and sheets with one full-screen, tabbed status screen. Reader
keeps its single reading column: the screen is an overlay, never a side panel.

## Acceptance

- One status screen with tabs **Character, Inventory, Quests, Journal, Codex, Map, Timeline,
  Settings**; C/I/Q/J/M open it on that tab and Esc returns to the story.
- Inventory is a paper doll (main hand, off hand, worn) plus a bag grid. Every item opens the same
  item card the story uses.
- Equip, move and sort are instant. Use, give, throw and drop send one story turn.
- Item icons come from game-icons.net (CC BY 3.0); `NOTICE` credits every icon and author.
- Styles live in `apps/web/src/menus.css`; Night Codex look, keyboard-first, AA contrast.

## Design decisions for this step

- The sheet's `EquipmentChanged` remains the combat-facing truth (D157). Equipping or stowing
  writes one validated `EquipmentChanged`; item stacks keep their carried quantity. The view
  derives an item's shown location from the sheet, so the bag and item card agree.
- Tabs are a real ARIA tablist. Arrow keys move between tabs; Esc closes the screen. The key hints
  (C/I/Q/J/M) are hints, never the accessible name.
- Quests is its own tab reading the journal view; Journal keeps recap, leads, clocks, rumours,
  summaries, notes and downtime.
