# Workstream A — Levels and abilities TDD plan

Branch: `w2-levels`. Scope: roadmap A, design §6, D130/D131/D153.

1. **Schemas/replay:** failing tests for positive integral Levels (open past 20 and `infinite`), effective levels, ranked abilities and defaults on older sheets. Define the four new events only in `domains/levels.ts`, their handlers only in `reduce/levels.ts`; proposals remain replayable until accepted or superseded.
2. **Resolution:** table-driven red/green tests for every gap row, cited exploits, effective levels, equal-level rank bonuses, infinity without RNG consumption, deterministic replay and power ratings at 1/9/20. Wrap the existing d20 resolver with native d20 bonuses; keep d100 mechanics intact. Every Levels bound, increment, band, formula and threshold belongs to `tuning.levels`.
3. **Progression:** failing tests for milestone proposal/explicit acceptance, stale/double acceptance, XP crossing multiple configured thresholds, and successful/failed breakthrough rolls (including costs). Engine functions validate actors, ranks and targets; events carry resolved values. Wire XP level awards into actual turn/GM XP paths.
4. **GM tools/API:** offline tests for opposition by level/actor, ability grants/ranking and proposal cards through `gm/tools/levels.ts` plus one index import. Extend the existing roll schema and engine check path. Test the acceptance route, running-turn conflicts and replay; no model may silently accept a milestone proposal.
5. **UI:** failing render tests for level/∞ in the strip, power/abilities on the sheet, ability hotbar entries and an actionable levelUp card. Bind cards to filtered GameView proposals and refresh after acceptance. Verify the flow with one Playwright process, sequential desktop/phone browsers.
6. **Finish:** run focused red/green checks throughout, `bun run check`, build and relevant e2e tests. Update spec/handoff/roadmap, review the diff, commit, merge to main and push to GitHub, then stop. Do not tick the whole W2 milestone for this one workstream.

Implementation choices: d20 checks without opposition treat the challenge as equal-level; an infinite actor never rolls (infinite-vs-infinite is an automatic stalemate/failure). XP thresholds are cumulative, configurable rows with an open-ended formula beyond the supplied table. Breakthrough success may carry an explicit engine-applied HP cost; failure never grants a level. Existing class levels are distinct from cosmic Levels.
