4. **Functional UI.** Add optional source/wiki fields, review controls for every proposed setting, and the sample's “More like…” loop. Reuse editable style fields in campaign Settings. Add offline server/render/browser coverage for the complete flow.
5. **Verify and ship.** Run focused tests, `bun run check`, build and one sequential Playwright run. Update HANDOFF and roadmap status, leaving aggregate W2/owner-only checks unticked. Fetch and rebase on current main (F is concurrent), rerun checks after integration, merge to main and push GitHub.

Implementation conventions: death rule uses existing hardcore/lethality/companionDeath settings; hunger/exposure use the existing survival/weather toggles, and encumbrance uses inventory mode. Source summaries are campaign canon with research confidence and URLs; raw wiki text and private house excerpts never enter committed files.
