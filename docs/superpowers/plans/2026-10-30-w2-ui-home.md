# W2 UI 2.0 U5 — Home and creation

Build on `w2-ui-home`, applying D150–D152 (Reader / Night Codex) to the screens outside play.

1. **Red: campaign management.** Test `PATCH /api/campaigns/:id` for rename and archive. Rename appends a replayable `CampaignRenamed` event, so the in-campaign title follows the home card; archive is app-store metadata only (`web_campaigns.archived`), and archived campaigns stay playable. Test the store migration and list projection.
2. **Red: the draft library.** Test `GET /api/world-drafts` summaries, `GET /api/world-drafts/:id` resume data, and `DELETE /api/world-drafts/:id`. Drafts live server-side in `creation_drafts`; started drafts are excluded. Test that an existing v2 draft stored in `settings` survives the migration.
3. **Functional home.** Restyle home in the Night Codex look with a new `apps/web/src/home.css`: ruled campaign rows, inline rename, archive/restore behind a disclosure, delete confirmation, and the unfinished-draft list with Continue and Discard. Home carries `data-preset="reader"`.
4. **Functional creation.** Restyle the creation dialog: an explicit original-world/source choice, the pitch, real generation progress (step state, elapsed time, `aria-live`), clear model errors with technical detail and a model-settings link, the world review, the GM's proposed settings, and the style sample with a "More like…" revise loop that reports its own progress and errors.
5. **Verify and ship.** Run focused server/storage tests, `bun run check`, build, then one sequential Playwright run (`--workers=1`, after no Playwright process is running). Add desktop and phone browser coverage for rename, archive, draft resume, source errors and style revision errors. Update HANDOFF, the roadmap and `docs/milestones.md`, add D156, fetch/rebase on main, rerun checks, merge and push.

Implementation conventions: archive/reopen never deletes history; only Delete does. `CampaignRenamed` changes the projected campaign name and the app-store card together. Drafts are resumable until their campaign starts. `Play.tsx` is not touched; `home.css` scopes every rule to the home/creation surfaces.
