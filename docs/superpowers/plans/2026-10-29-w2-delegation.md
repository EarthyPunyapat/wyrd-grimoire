# Workstream F — companions, Ari and delegation TDD plan

Branch: `w2-delegation`. Scope: roadmap F, design §11, D138/D153; use A's level resolution.

1. **Loyalty and voice (red → green):** verify a loyal companion cannot lose approval, confront, betray or leave, including replay of direct old events. Store an editable voice profile through an event/API and include it in GM/narrator speaker guidance. Keep ordinary companions' approval behaviour intact. New events/handlers stay in the delegation domain pair; move the affected existing handlers there to enforce the invariant without another shared switch.
2. **Tasks (red → green):** validate an active living companion, goal, due time, skill/owned ability and opposition. Store TaskAssigned/Progressed/Blocked/Ended under replayable delegation state. Use seeded A level checks at the resolution boundary, including rank/exploit/infinity rules; success/failure are engine decisions. Missing/unavailable actors or impossible unexploited gaps block and ask for help. Blocked tasks can be explicitly reassigned.
3. **Time and reports (red → green):** exercise real turns, time_skip and downtime; no advance means no progress, terminal tasks never reroll, replay reproduces RNG/state, and long/split advances agree for task resolution. A blocked-task helper is E's interruption contract; the existing GM skip stops at the first blocked task boundary. Task reports use the existing report card and reach both model tool results and persisted browser turns.
4. **Tool/API/prompt/UI (red → green):** register delegate in `gm/tools/delegation.ts` and import once. Provide a companion loyalty/voice configuration route; expose only party-visible companion/task data. Hide loyal approval meters and show a companion-specific delegation hotbar action ("Delegate to Ari" for Ari), prefilling the composer. Test voice guidance and secret-free model/browser output offline.
5. **Verify and finish:** focused tests after red/green steps, `bun run check`, build and sequential desktop/phone browser tests (one browser/worker at a time). Update handoff/spec/roadmap, review the diff, commit, merge to main and push to GitHub, then stop. Remaining W2 acceptance stays unticked.

Defaults are configurable under tuning.delegation: a task without due time resolves after one day; due is an absolute game-minute boundary. Task checks use d20 Levels even in legacy campaigns. No NPC mind or secret fact enters a task report or voice profile automatically. Loyalty is persistent, not a switch that a model can silently turn off; loyal companions can still die under campaign rules. Ari is not spawned into unrelated campaigns; source/import/configuration establishes the companion and her voice.
