# M4 — Combat: build roadmap

M4 is too big for one plan. Like M2 (steps A–G), it is built as stacked steps on branch `m4-combat`,
each ending green (`bun run check`, `bun run test:e2e`) and committed. Each step gets its own
detailed plan in this folder, written when the previous step lands, so it can cite real interfaces.

Spec: [03](../../spec/03-combat-and-injury.md), [08 combat mode](../../spec/08-turn-pipeline.md),
[13 combat panel](../../spec/13-ui.md), [15 golden combat + AI tactics](../../spec/15-testing.md),
mockup `docs/design/play-and-combat.html` (Combat view).

| Step | Delivers | Engine/IO | Plan |
|---|---|---|---|
| **A** Damage and injury | dice roller, body plans, equipment on the sheet, hit → location → armour → damage → HP/Down → wounds and their check penalties → bleeding ticks → lethal checks and fate | pure engine + core schemas + pack data | [m4a](2026-10-28-m4a-damage-and-injury.md) |
| **B** Combat state | `GameState.combat`: zone graph reuse/validation, positions, engagement, surprise, initiative (groups, delay, arrivals), rounds, 3 AP, reactions, death clocks; `CombatStarted/RoundStarted/TurnStarted/CombatEnded` events | pure engine | later |
| **C** Combat actions | every core action from the AP table with validation tables (exact error codes), attacks with Dodge/Parry, range bands and LoS, multi-attack, aim, cover, opportunity attacks, grapple/shove/trip/disarm, first aid and stabilise, hide, ready, intimidate/rally, reload, stunt vocabulary; Luck on opposed checks (D47) | pure engine | later |
| **D** Tactics | utility AI with profiles, goals and difficulty depth; morale; companion directives; creature stat blocks + ≥10 fantasy-core creatures; **golden combat scenarios** | pure engine + pack | later |
| **E** Endings | loot from canon inventories/loot tables, defeat outcomes (weighted, seeded) with a new hook, hardcore death, obituary/epilogue role, Legacy start | engine + llm | later |
| **F** Pipeline combat mode | `propose_zone_map`, combat parser actions (multi-action free text), clarification with legal alternatives, AI turns until the PC's turn, required beats, two-passage pacing + fast combat, guard; exploration → combat via `start_combat` | llm | later |
| **G** Combat panel | `CombatView` in GameView (PC-knowledge filtered), initiative strip, zone diagram, AP pips, legal action chips, target card with silhouette, phone strip + bottom sheet; e2e tavern brawl | server + web | later |

Acceptance (milestones.md M4) is checked after G.

Deliberately deferred out of M4 (record as decisions when step A lands):
- Infection, fracture setting/healing, wound healing over days, short/long rests and permanent injuries
  need the calendar and world ticks (M5). M4 records `fracture` on wounds and applies its penalties.
- Chases (extended task on a chase clock) need clocks; M5 with Threat Clocks.
- Barks via `npcDialogue` are optional in spec 03; step F adds them only if time allows.
