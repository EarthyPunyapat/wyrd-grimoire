# M5 — World and memory: build roadmap

Built directly (owner's call, 2026-10-29) in stacked steps on `m5-world-memory`. Each step ends green
(`bun run check`, `bun run test:e2e`) and is committed. One whole-branch review runs at the end.

Spec: [06](../../spec/06-world-and-story.md), [07](../../spec/07-memory.md), [13](../../spec/13-ui.md)
(Journal, Codex, Map, reference cards, forms of address), [15](../../spec/15-testing.md) (evals).

**Architecture:** world-simulation state lives in `GameState`, so ticks are pure and replayable. That
covers time, calendar, clocks, factions, quests, the social graph (edges), NPC minds, rumours and PC
knowledge. Storage keeps rebuildable projections for querying (codex, retrieval index). Canon entities
and facts stay in projections as before, plus retcon/supersede/pin events.

| Step | Delivers |
|---|---|
| **A** World state | Calendar and time of day, clocks, social edges, factions (reputation tiers, relations, goal clocks), quests with engine-checked objectives, PC knowledge (learned how), NPC minds (memories, dispositions), rumours; hourly, daily and weekly ticks (rumour spread with seeded distortion, faction goals, Threat Clock pace, weather); story-mode switching; retcon, supersede and pin |
| **B** Who knows what | Telling and lying (`told` memories with belief from Deception vs Insight), witnesses per turn, `reportsTo` spread; the lie-reaches-the-captain demonstration |
| **C** World generation | Stage 1 (premise, regions/sites/routes, factions, threat, key NPCs, hooks) and stage 2 (start site, opening) as small validated `worldGen` calls; name registry; lazy generation (location, NPC, elaborate); travel along routes with encounter tables |
| **D** Memory | Pyramid (scene/chapter/arc boundaries, `summarizer` role), session recap, retrieval index (FTS5 + vectors + RRF + rerank, offline hashed embeddings), the complete assembler, guard v2 (secrets, lines, witnesses, objectives, approval) |
| **E** UI | Journal, Codex (pin, retcon), Map, narration reference cards, setting-aware forms of address |
| **F** Evals and acceptance | Memory recall eval (≥ 0.9 @10), NPC-knowledge eval, a 100-turn three-site soak on the offline provider, acceptance ticks |

Owner-only checks after F: a 100+ turn real-model run from a pitch, and the real-model memory and
NPC-knowledge evals.
